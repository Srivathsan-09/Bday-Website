## 🌟 The Experience Journey

1. **Scene 0 — The Awakening (Loader)**: Minimal dark stardust space with percentage counter and *"Ready."* transition.
2. **Scene 1 — The Intro**: Distant floating memory cards in deep space, sequential emotional typography, and an interactive **"Enter →"** button.
3. **Scene 2 — Her Name**: Monolithic, statuesque serif typography **MANISHA**, with her 8 physical photo cards orbiting at varied depths with realistic tilt, shadows, and mouse/touch parallax.
4. **Scene 3 — January 2025 (Timeline)**: A glowing 3D timeline path emerging from `JANUARY 2025` forward, with her photos along the journey.
5. **Scene 4 — Distance**: Two distant celestial beacons (representing Nashik and you) bridged by an undulating, warm luminous ribbon of light.
6. **Scene 5 — Her Photos (3D Interactive Carousel)**: Cylindrical 3D gallery where her 8 photographs float in space. Drag, swipe, or click any photo to bring it smoothly toward the camera, tilt it in 3D with your cursor, and read gentle captions (*"You, being you."*).
7. **Scene 6 — Photo Constellation**: Her 8 photos configured as glowing stellar nodes in an interconnected 3D constellation.
8. **Scene 7 — The Birthday Message**: A quieter intimate mood with a single glowing beacon and a frosted 3D glass card revealing the heartfelt personal message line-by-line.
9. **Scene 8 — The 3D Birthday Cake**: Luxury stylized 3D cake with a golden **"MANISHA"** plaque and interactive candles with flickering flames. Tapping blows out the candles, dims the room, triggers sound effects, and bursts celebratory golden sparks.
10. **Scene 9 — Final Reveal**: Her 8 photographs orbit gracefully in a halo around *"Happy Birthday, Manisha"*, followed by the playful closing lines and replay options.

## 🎵 Soundtrack & Audio
- **Generative Ambient Piano Engine**: Built using the Web Audio API with warm Eb Major / Ab Major piano voicings and celestial chimes, requiring no external streaming or files.
- **Custom Audio Support**: You can drop any song file as `public/music.mp3` and the top-right music button will smoothly play it.
- **Sound Effects**: Realistic breath extinguish noise when blowing out the candles, followed by acoustic starlight chimes.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

---

## ☁️ Deploying to Vercel

### Option 1: GitHub / Vercel Dashboard
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your repository. Framework preset will automatically detect **Vite**.
4. Click **Deploy**.

### Option 2: Vercel CLI
```bash
npx vercel
```
